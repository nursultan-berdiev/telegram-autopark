## REST API (для команд и резолва устройств)

База: `${TRACCAR_URL}/api`.
- `POST /api/session` — форма `email=<...>&password=<...>` → cookie сессии (держать в httpx-
  клиенте, реконнект при 401). Для прода **завести отдельного сервисного пользователя Traccar**
  (учётка из пилота — на сервере, для реюза не полагаться). [ИСТОЧНИК: Traccar API]
- `GET /api/devices` → `[{id (numeric), uniqueId, name, status, lastUpdate}]`. **Резолв
  `external_id (uniqueId)` → `deviceId (numeric)`** — кэшировать.
- `GET /api/positions` → последние позиции (`deviceId, deviceTime, latitude, longitude, speed,
  course, altitude, valid, attributes{...}`). Фолбэк-polling, если WS выключен.
- `POST /api/commands/send` — JSON `{"deviceId": <numeric>, "type": "<traccar type>"}` →
  постановка/исполнение. Ответ трекера приходит отдельным событием/в атрибутах.
- `GET /api/reports/route|events|summary|stops|trips` — исторические отчёты (при необходимости).

## WebSocket (для ингеста телеметрии)

- `GET /api/socket` (после `/api/session`, тот же cookie) → JSON-кадры с ключами
  `positions[]`, `devices[]`, `events[]`. Основной источник живой телеметрии для адаптера.
- Каждый элемент `positions` = как в REST-позиции (см. поля ниже). Реконнект с бэкоффом.

## Команды: маппинг наш → Traccar → провод [ФАКТ, проверено на 139]

| Наш `CommandType` | Traccar `type` | На проводе | Проверено |
|---|---|---|---|
| `engine_stop`   | `engineStop`   | `S20,1,1` | ✅ `S20,OK`, реле стоит, двигатель не завёлся |
| `engine_resume` | `engineResume` | `S20,1,0` | ✅ `S20,OK`, завелась после снятия |
| `alarm_arm`     | `alarmArm`     | `SCF,0,0` | ✅ ответ `SCF,0` |
| `alarm_disarm`  | `alarmDisarm`  | `SCF,1,1` | ✅ ответ `SCF,1` |
| (интервал)      | `positionPeriodic` | `S71,22,N` | ❌ прошивкой ST-901M **игнорируется** — не использовать |

> Блокировка двигателя (`engineStop`) требует физического реле в цепи. На 139 — есть [ФАКТ].
> По остальным машинам наличие реле **не подтверждено** — проверять безопасным протоколом
> (машина стоит → block → попытка завести → resume). Ответ трекера `S20,OK` = принято трекером,
> НЕ гарантия наличия реле.

## Телеметрия: поля позиции и нормализация

Из атрибутов Traccar-позиции адаптер строит `NormalizedPoint` (см. 04):
- `latitude, longitude, speed (узлы), course, altitude, valid (A/V), deviceTime`.
- `attributes.ignition` (bool) — Traccar извлекает из статус-маски; = **бит 10**.
- `attributes.motion` (bool).
- `attributes.totalDistance` (**метры**) → `total_distance_km = /1000` (одометр).
- `attributes.status` (число) — H02 статус-маска; `status_raw` = hex.
- `attributes.io1..io4` — сырые каналы (у 139: `437, 09, 7111, <плавает>`; смысл io не
  подтверждён) → в `attributes` JSONB.
- `attributes.protocol = "h02"`.

## Статус-маска H02 — две подтверждённые формулы [ФАКТ-док на 139]

Не выводить общих правил «0=активно/1=активно» (у разных битов по-разному). Использовать только
эти две подтверждённые формулы, остальное — из `attributes` Traccar:
- **Зажигание** — брать готовое `attributes.ignition` (Traccar сам декодирует; соответствует
  биту 10, где `1` = заведён). Самим маску под зажигание не парсить.
- **Блокировка двигателя** — `engine_blocked = not ((status >> 27) & 1)` (бит 27 = `0` →
  заблокирован). Подтверждено окном engineStop/Resume на 139.
- бит 26 — наблюдался разово, триггер неизвестен [?] — **не использовать**.
- Прочие биты у 139 за сеанс были стабильны — доп. смыслов не извлекать без проверки.
Примеры значений: `0xFFFFFFFF` (зажигание вкл), `0xFFFFFBFF` (зажигание выкл), `0xF7FFFBFF`
(блокировка + зажигание выкл), `0xF7FFFFFF` (блокировка + зажигание вкл).

## Формат кадра H02 (справочно, парсит сам Traccar)
```
*HQ,<ID>,V1,<ЧЧММСС>,<A|V>,<ггмм.мммм>,<N|S>,<гггмм.мммм>,<E|W>,<скорость_узлы>,<курс>,<ДДММГГ>,<статус_hex>,<io1>,<io2>,<io3>,<io4>#
```
Ответ сервера: `*HQ,<ID>,V4,V1,<YYYYMMDDHHMMSS>#`. Адаптер это не парсит — работает через
Traccar REST/WS.

## Тестовый поток телеметрии без живого авто
Если тест-машины под рукой нет: поднять **Traccar Client** (приложение) на телефоне, протокол
OSMAnd (порт 5055 — открыть в Traccar/файрволе), завести устройство в Traccar, ходить/ездить с
телефоном. Даст живой поток в тот же Traccar для проверки ингеста адаптера. (Команды двигателя
на таком «устройстве» не применимы — только геоданные.)
