# Проверка штрафов парка (расширение Chrome)

Прогоняет госномера парка через форму [carcheck.gov.kg](https://carcheck.gov.kg/ru)
и заводит найденные штрафы в core-api через `POST /fines/import`.

## Почему расширение, а не скрипт на сервере

Ключ reCAPTCHA v3 привязан к домену: валидный токен можно получить только в
контексте страницы `carcheck.gov.kg`. Скрипт на сервере или локальная страница
такой токен не получат в принципе.

Расширение **не обходит защиту**: оно подставляет номер в поле и нажимает
кнопку — те же действия, что и человек. Токен выпускает сама страница в браузере
владельца. Если сервис отказывает (в том числе `CAPTCHA_LOW_SCORE`), прогон
останавливается и показывает причину.

## Установка

1. `chrome://extensions` → включить «Режим разработчика» → «Загрузить распакованное»
   → выбрать папку `tools/carcheck-runner`.
2. Открыть настройки расширения и заполнить адрес core-api, `FINES_IMPORT_TOKEN` и
   Telegram-id админа. При сохранении браузер спросит доступ к адресу core-api.

   Токен здесь узкий: он открывает только `POST /fines/import` и список номеров
   парка. `CORE_API_TOKEN` сюда класть нельзя — он даёт весь домен, включая
   блокировку двигателя, а расширение живёт в браузере и синхронизируется с
   профилем. Адрес принимается только по `https` (исключение — `localhost`,
   трафик до петли не перехватить).
3. Открыть `https://carcheck.gov.kg/ru`, нажать на иконку расширения →
   «Проверить парк».

## Пробный прогон

По умолчанию включён пробный режим: расширение собирает ответы сервиса, но
ничего не пишет в core-api. Сырые ответы видны в настройках расширения.

Он нужен по конкретной причине: успешный ответ сервиса мы вживую ещё не видели —
все проверки упирались в капчу, — поэтому имена полей в
[`mapping.js`](mapping.js) (`REF_KEYS`, `AMOUNT_KEYS`, `DATE_KEYS`) подобраны
по кандидатам. После первого реального прогона нужно посмотреть сырой ответ и
поправить эти списки, и только потом снимать галочку «Пробный прогон».

Разбор ответа вынесен в отдельный модуль именно потому, что его придётся
править: `node --test tools/carcheck-runner/mapping.test.mjs`.

Нарушения без номера постановления не импортируются: без него повторный прогон
завёл бы дубль.

## Ограничения

- Работает, пока открыт браузер владельца; расписания нет — только кнопка.
- Пауза между номерами — 7 с плюс случайная добавка. Меньше 5 с ставить не стоит.
- Селекторы (`input[name='govPlate']`, кнопка «Проверить») зависят от вёрстки
  сайта. Если она изменится, прогон остановится с понятной ошибкой, а не молча.
