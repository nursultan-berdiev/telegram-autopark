# web-admin

SPA веб-админки автопарка (React + Vite + TypeScript). Ходит в `core-api`
под одним origin; данные и мутации — те же JSON-эндпойнты, что у бота.

## Запуск (dev)

```bash
npm ci
npm run dev        # Vite на :5173; /api и /admin проксируются в core-api
```

Адрес core-api задаётся `CORE_API_ORIGIN` (по умолчанию `http://127.0.0.1:8099`).
Прод/дев-стенд собирают статику и раздают её через Caddy:

```bash
npm run build      # tsc --noEmit + vite build → dist/
npm test           # vitest
```

На dev-стенде Caddy отдаёт `dist/` и проксирует `/api` → `core-api`
(см. `fleet-dev`), адрес — `http://100.66.86.35:8095/`.

## Аутентификация

Вход — одноразовой ссылкой из бота: `GET /admin/login?token=…` ставит
подписанную httponly-куку `autopark_admin`. На чтениях (GET) кука проходит
без доп. заголовков; на мутациях клиент шлёт `X-Requested-With` (CSRF).
Все админ-действия перепроверяются на сервере.

## Страницы

| Маршрут | Назначение |
|---|---|
| `/` | Дашборд: счётчики, открытые алерты, парк сейчас |
| `/cars`, `/cars/:id` | Автопарк: список, карточка (фото, состояние, двигатель, трекер, ТО, документы, штрафы) |
| `/drivers`, `/drivers/:id` | Водители: список, карточка (селфи, график платежей, фотоконтроль) |
| `/announcements` | Объявления: рассылка и история |
| `/periodic` | Периодические задачи (celery beat) |
| `/documents` | Общие документы парка (просмотр/удаление; загрузка — через бота) |
| `/photo-inspections`, `/photo-inspections/:id` | Фотоконтроль: статусы водителей и альбом осмотра по ракурсам |
| `/reports` | Отчёты |
| `/journals` | Журналы: аудит, прогоны задач, очередь отправок, алерты |

Пункт «Карта ↗» в сайдбаре открывает Traccar в новой вкладке по
короткоживущему SSO-токену (`POST /api/traccar/sso`).

## Медиа

Фото машин, селфи водителей, документы и кадры фотоконтроля хранятся в
Telegram (file_id). Показываются через прокси `GET /api/media/{kind}/{ref}`
(`car-photo` / `driver-selfie` / `document` / `inspection?angle=…`): картинки —
inline, прочее (PDF) — вложением.
