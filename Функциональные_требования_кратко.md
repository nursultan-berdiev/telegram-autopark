# Telegram-бот для автопарка — краткое описание

**Этап 1:** регистрация водителей и учёт платежей.
*(Управление GPS-трекерами — включение/выключение двигателя, геолокация — на следующем этапе.)*

---

## Роли

- **Администратор (владелец)** — задаётся только в настройках при запуске бота, не через сам бот. Может быть несколько.
- **Водитель** — регистрируется только по одноразовой ссылке от админа.
- **Посторонний** — без ссылки доступа к боту нет.

## Автопарк

- Автомобили в систему заводит **администратор** — с указанием данных и **фото** машины.
- У каждой машины статус: свободна / занята.

## Приглашение и регистрация водителя

1. Админ нажимает **«Новый водитель»** и сам выбирает свободную машину.
2. Бот генерирует **одноразовую ссылку** — админ отправляет её водителю.
3. Водитель переходит по ссылке → открывается бот → открывается форма регистрации.
4. Водитель вводит: ФИО, телефон, **ИНН**, **селфи**. *(Паспорт не запрашиваем и не храним.)*
5. После селфи водитель зарегистрирован, машина закреплена за ним.

Ссылка одноразовая и действует **24 часа**. Одна машина = один водитель.

## Платежи

- У каждого водителя **свой график и сумма** — задаёт админ, периодичность **гибкая** (день/неделя/месяц/произвольно).
- Водитель оплачивает через банк, в боте нажимает «Оплатить» и **отправляет чек**.
- **ИИ (Claude)** читает чек, показывает водителю сумму и время, спрашивает подтверждение.
- После подтверждения платёж фиксируется, а **владельцу приходит уведомление**: кто, сколько, + сам чек.

## Отчёты для владельца

Кнопками в боте:
1. **Список машин + водители** (по каждой машине — кто закреплён, свободные помечены).
2. **Кому скоро платить** — водители, у которых по графику приближается срок оплаты.
3. **Выписка по оплатам** — по машинам и по водителям (кто, когда, сколько).

Дополнительно владелец может задать ИИ **произвольный запрос** и получить сводку в свободной форме.

## Данные

Хранятся на сервере: ФИО, телефон, ИНН, селфи водителя, фото машин, чеки. **Паспортные данные не собираются.**
